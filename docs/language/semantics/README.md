# Tynel 语言语义索引

> 文档版本：0.1  
> 修订日期：2026-11-15  
> 当前里程碑：Tynel Language Preview 0（`mvp/06-compiler-mvp`，2026-11-09）  
> 关联文档：[语言宪章](../../../LANGUAGE.md)、[兼容性矩阵](../compatibility.md)、[长期路线图](../../../ROADMAP.md)

## 1. 作用

本索引是 Tynel 语言语义的规范入口。每个语义领域在这里登记状态、规则摘要和详细文档；没有登记为「已定义」的行为，不能从当前实现、Go Runtime 或某个后端的偶然表现反推为语言规范。

状态分为六种：

| 状态 | 含义 |
| --- | --- |
| 已定义 | 有明确的 Tynel 规则、可执行用例和验证记录 |
| 部分定义 | 只覆盖 Preview 0 的子集，未覆盖部分不得类推 |
| 已确认 | 决策已记录，尚未实现，不能当成当前能力 |
| RFC 草案 | 已有设计提案，尚未决策 |
| 未定义 | 尚无 Tynel 规则，等待 RFC 或 ADR |
| 不适用 | 当前语言目标之外 |

## 2. 已定义的语义

| 领域 | 规则摘要 | 详细文档与证据 |
| --- | --- | --- |
| `number` 表示 | 固定为 IEEE 754 binary64；NIR 保存 64 位位模式；负零、NaN 和正负无穷有固定行为 | [比较语义](../../reference/comparison.md)、[03.02 验收](../../validation/03-02-compare.md) |
| 数字字面量 | 按 JavaScript `Number` 规则解析，不在后端做十进制重解析 | [降低器](../../reference/lowering.md)、[02.05 验收](../../validation/02-05-lower.md) |
| 算术运算 | `+` `-` `*` `/` 接受两个 `number`；左右操作数按源码顺序求值 | [降低器](../../reference/lowering.md) |
| 比较与严格相等 | `<` `<=` `>` `>=` 只接受 `number`；`===` `!==` 要求两侧同为 `number`、`boolean`、`string` 或同一对象形状；对象比较引用身份；NaN 比较遵循 IEEE 754 | [比较语义](../../reference/comparison.md)、[03.02 验收](../../validation/03-02-compare.md) |
| `string`（部分定义） | UTF-16 code unit 存储；字面量、`+` 拼接、`length`、`===` / `!==` 和 `console.log` 可用；索引、`slice`、模板插值和字符串方法未定义 | [字符串 RFC](strings.md)、[S2.1 验收](../../validation/s2-01-nir-schema-3-string.md) |
| 静态对象（部分定义） | 静态形状、必填属性、对象字面量、字段读取和引用身份；对象 `===` 不比较内容 | [对象与数组 RFC](objects-arrays.md)、[S2.2 验收](../../validation/s2-02-objects.md) |
| 数组与元组（部分定义） | 同质数组与定长元组；字面量按源码顺序求值，索引先求值数组再求值下标；`length` 返回当前元素个数；数组越界按数据错误退出 6，元组越界在编译期拒绝 | [对象与数组 RFC](objects-arrays.md)、[S2.3 验收](../../validation/s2-03-arrays.md) |
| 可空联合（部分定义） | `T \| null` / `T \| undefined`；空值比较生成标签检查；前端缩窄后的成员读取由降低器显式拆箱；标签不一致按数据错误退出 6 | [联合与空值 RFC](unions-null.md)、[S2.4 验收](../../validation/s2-04-nullable-unions.md) |
| 函数值（部分定义） | 无捕获箭头提升成合成具名函数；顶层函数值、函数类型参数/返回值和间接调用；函数值不能输出，也没有身份比较 | [函数与闭包 RFC](functions.md)、[S2.5 验收](../../validation/s2-05-function-values.md) |
| `boolean` | `true` / `false` 是独立标量；不做数字真假转换；`!` 只接受 `boolean` | [03.01 验收](../../validation/03-01-boolean.md) |
| `void` | 只表示「没有值」；只能作为函数返回类型和调用语句的结果 | [输出格式](../../reference/output.md)、[02.06 验收](../../validation/02-06-void.md) |
| 求值顺序 | 调用实参、二元操作数、条件与分支准备语句按源码顺序执行；右侧准备语句不能提前到左侧之前 | [降低器](../../reference/lowering.md)、[03.07 验收](../../validation/03-07-combine.md) |
| 条件求值 | `if` 和 `while` 的条件必须是 `boolean`；条件只求值一次；未选中的分支不执行但照样检查 | [分支](../../reference/branches.md)、[03.03 验收](../../validation/03-03-branch.md) |
| 返回路径 | 有值函数的每条路径都必须结束；`if` 只有两臂都结束才算覆盖 | [返回路径](../../reference/returns.md)、[03.04 验收](../../validation/03-04-returns.md) |
| 布尔短路 | `&&` / `||` 左侧求值一次；未选中的右侧不执行；结果绑定到临时值 | [短路求值](../../reference/short-circuit.md)、[03.05 验收](../../validation/03-05-short.md) |
| 三元式 | 条件求值一次；只有选中的分支执行；两臂必须同为标量、同一对象形状、同一数组或同一元组 | [三元式](../../reference/ternary.md)、[03.06 验收](../../validation/03-06-ternary.md) |
| 声明与可变性 | `const` 不可赋值；`let` 必须带初值；赋值右值先求值再写入；赋值只作为独立语句 | [声明与可变存储](../../reference/mutability.md)、[04.01 验收](../../validation/04-01-mutability.md) |
| 循环与跳转 | `while` 每轮重新检查条件，可能零次执行；`break` / `continue` 只作用于最近循环；循环体有独立作用域 | [循环跳转](../../reference/jumps.md)、[04.03 验收](../../validation/04-03-while.md) |
| 递归与调用层 | 直接递归和相互递归共用签名预登记规则；每层调用持有独立参数和局部值 | [递归与调用层](../../reference/recursion.md)、[04.05 验收](../../validation/04-05-recursion.md) |
| 模块绑定 | 命名导入绑定到导出声明的完整身份；类型导入不产生运行时绑定 | [跨模块名称绑定](../../reference/module-bindings.md)、[05.04 验收](../../validation/05-04-bindings.md) |
| 模块初始化 | 按源码导入顺序深度优先；共享依赖只执行一次；纯类型依赖不执行 | [初始化顺序](../../reference/init-order.md)、[05.05 验收](../../validation/05-05-init.md) |
| 模块合并 | 全部模块合并成一个 NIR；模块函数加前缀，模块体变成 `__init$N`；入口按顺序调度 | [合并模块](../../reference/merged-program.md)、[05.06 验收](../../validation/05-06-merge.md) |
| 输出 | `console.log` 只接受一个 `number`、`boolean` 或 `string`；有限值最短可回读，负零、NaN、正负无穷有固定拼写；字符串在输出边界转成 UTF-8 | [输出格式](../../reference/output.md)、[02.06 验收](../../validation/02-06-void.md) |
| 错误分类 | 源码错误、能力限制、数据错误和内部故障分开报告；没有语言级异常 | [诊断协议](../../reference/diagnostics.md)、[06.02 验收](../../validation/06-02-diagnostics.md) |
| 内存与对象身份（部分定义） | 静态对象有用户可见的引用身份：`===` 比较指针，不比较字段；数组和元组暂时没有身份比较。布局和 GC 可见指针格式仍是当前后端选择，不是长期语言契约 | [Go 桥接与运行时](../../../site/internals/go-bridge.md)、[S2.2 验收](../../validation/s2-02-objects.md)、[S2.3 验收](../../validation/s2-03-arrays.md) |

标为「部分定义」的行只覆盖已经实现并通过验证的子集：字符串有最小闭环，对象有静态形状第一个切片，数组和元组有字面量、索引与长度，联合有可空两成员切片，函数值有无捕获箭头与间接调用切片；未覆盖部分不能从当前实现类推。

## 3. 未定义的语义

以下领域尚未形成完整的 Tynel 规范。实现中出现的任何布局、指针或运行时行为都只是当前后端选择，不能作为语言语义引用。Stage 2 的五份 RFC 已经确认；字符串最小闭环、对象第一个切片、数组/元组第一个切片、可空联合第一个切片和函数值第一个切片已经实现，其他领域仍是待实现设计，不改变兼容性矩阵里的 `rejected` 状态。

| 领域 | 状态 | 必须先决定的问题 | 决策入口 |
| --- | --- | --- | --- |
| 对象模型（扩展） | 已确认 | 可选属性与显式 `undefined`；字段写入；结构性放宽和对象复制规则 | [对象与数组 RFC](objects-arrays.md) |
| 数组模型（扩展） | 已确认 | 数组方法、扩容、切片共享与身份比较；首版只做同质字面量、索引和长度 | [对象与数组 RFC](objects-arrays.md) |
| 联合、`null` 与 `undefined`（扩展） | 已确认 | 多成员与判别联合；`??` / `?.`；可选属性与显式 `undefined` 的区分；`in` / `typeof` 缩窄 | [联合与空值 RFC](unions-null.md) |
| 函数值与闭包（扩展） | 已确认 | 闭包捕获与生命周期；块体与 `void` 箭头；函数值身份比较；跨模块函数值 ABI；函数类型兼容 | [函数与闭包 RFC](functions.md) |
| 泛型表示 | 已确认 | 类型擦除、单态化还是字典传递；约束与默认类型参数；与 Runtime ABI 的关系 | [泛型 RFC](generics.md) |
| 异常与错误模型 | 未定义 | 语言级异常、`Result` 类型或两者并存；栈展开；跨模块和跨 ABI 行为 | 阶段 3 / 4 RFC |
| 异步与 Promise | 未定义 | Promise 语义；事件循环或调度器；`async` / `await` 的求值顺序；与原生 I/O 的关系 | 阶段 3 / 4 RFC |
| 内存管理与 GC | 未定义 | 分配策略；对象身份；写屏障；栈逃逸；GC 可见指针布局；是否替换 Go GC | 阶段 2 / 5 RFC |
| 用户态并发 | 未定义 | 任务模型；共享内存与消息传递；是否暴露 goroutine 或 channel 类似概念 | 待定 |
| FFI 与 Native ABI | 未定义 | 函数 ID、签名、效果声明、目标平台清单、ABI 版本；跨语言生命周期 | 阶段 4 RFC |
| 定宽整数、`bigint`、取余与位运算 | 未定义 | 是否引入、以什么语法和运行时表示引入 | 待定 |

## 4. 语义文档的最低内容

每个从「未定义」转为「已定义」的领域，至少需要说明：

1. 哪些源码写法属于该语义；
2. 可观察行为和求值顺序；
3. 边界值、错误行为和未选中路径的处理；
4. 与其他特性的组合规则；
5. 对应的正向、负向和运行时用例；
6. 哪些实现选择不属于语言契约。

语义文档先描述行为，再解释当前后端如何实现。不得把「Go 这样实现」写成「Tynel 规定如此」。

## 5. 变更流程

- 影响语言语义的改动先写 ADR 或 RFC，再修改本索引与[兼容性矩阵](../compatibility.md)。
- 新增 `supported` 能力必须同时更新矩阵、本索引和验证记录。
- 发现实现细节正在未经记录地决定用户可见行为时，先补语义文档，再决定是否保留该行为。
- 完成标签不可移动；语义修订用独立文档提交记录。
